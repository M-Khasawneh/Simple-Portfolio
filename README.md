## 🚀 Getting Started

### 📋 Prerequisites

No special backend environment is required.

You only need:

```text
Web Browser
Git
Code Editor (Recommended: VS Code)
```

### ⚡ Run Locally

Clone the repository:

```bash
git clone https://github.com/M-Khasawneh/Simple-Portfolio.git
```

Navigate to the project:

```bash
cd Simple-Portfolio
```

Open the project using your preferred code editor.

You can then open `index.html` directly in your browser or use **Live Server** in VS Code.
